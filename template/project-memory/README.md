# Project Memory

This directory contains exploratory material, hypotheses, observations,
research notes and possible future directions.

Nothing here is a requirement, commitment, architectural constraint or accepted
decision unless it is explicitly promoted into the normative specification,
an ADR, an accepted plan or architecture documentation.

Typical progression:

1. Raw material enters `inbox/`.
2. Reusable possibilities move to `ideas/`.
3. Important questions become `investigations/`.
4. Actual decisions move to `docs/decisions/`.
5. Accepted implementation work may be described in `docs/plans/`.
6. Implemented architecture is documented in `docs/architecture/`.

Old or rejected material may move to `discarded/`.
