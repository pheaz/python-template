# Decisions

Accepted project and architectural decisions.

Use ADRs when a choice has actually been made and future contributors need to
understand what was decided and why.

Recommended structure:

- Context
- Considered options
- Decision
- Consequences
- Date

Name records sequentially, for example:

`0001-use-sqlite-for-local-state.md`

Unresolved questions belong under `project-memory/`.
